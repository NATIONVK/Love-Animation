# ❤️ Love Animation — Infinite Glow

A continuous, cinematic romantic heart experience built with pure HTML, CSS and JavaScript.

## ✨ Experience
- A luminous red/pink heart with a smooth, natural heartbeat.
- Floating ambient particles with soft bloom and twinkling light.
- Layered pink, rose and violet atmospheric glow.
- Tap or click the heart to release a burst of glowing particles.
- Responsive layout for mobile and desktop.
- No frameworks, external libraries, tracking scripts or build step.
- Respects reduced-motion preferences.

## 🚀 Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. Wait for GitHub Pages to finish deploying.

Your site will be available at:
https://nationvk.github.io/Love-Animation/

## 🧰 Run locally
Open `index.html` in any modern browser.
