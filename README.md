## ✨ The experience
A continuous canvas-rendered cinematic journey with scene-specific atmospheres, motion, particle behaviour and text treatments — not a slideshow or static gallery.
1. **Infinity Galaxy** — spiral arms, cosmic depth, stars and a glowing heart.
2. **Heart Made of Stars** — layered heartbeat, orbiting energy rings and light.
3. **Rose Universe** — moonlit rose garden, drifting petals and fireflies.
4. **Rain of Love** — neon city, rain streaks, reflections and a heart in the storm.
5. **Moonlight Experience** — moon, night sky and a heart constellation.
6. **Love Letter** — animated envelope and handwritten-style letter.
7. **Forever & Always** — luminous infinity path and particle trail.
8. **Butterfly Garden** — glowing butterflies and flowers.
9. **Sky Full of Wishes** — floating golden lanterns.
10. **Heart Ocean** — moonlit waves and glowing reflections.
11. **Firework of Love** — colourful particle bursts.
12. **Cherry Blossom Dream** — drifting petals and a Japanese-inspired garden.
13. **Universe of Two Hearts** — two lights move together and merge.
14. **Grand Finale** — a large glowing heart and cinematic declaration.
15. **Always You** — a quiet, living final chapter.
## 🎬 Controls
- Start, pause/resume, previous/next scene, direct scene selection and progress.
- Optional original ambient audio generated with Web Audio API; volume control.
- Low / Medium / High graphics, reduced motion and fullscreen.
- Cinematic auto-hide mode for controls.
- Local customization: recipient, sender, title, final message and heart colour.
- Keyboard: **Space** pause/resume, **← / →** previous/next.
## 📱 Performance
- Canvas 2D renderer with delta-time updates and capped frame delta.
- Adaptive particle budgets and capped device pixel ratio.
- Responsive touch controls and reduced-motion support.
- LocalStorage customization; no account, server, API key or backend.
- Optional service worker for offline caching after first successful visit.
## 🚀 Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Select **Deploy from a branch**.
3. Choose **main** and **/(root)**, then **Save**.
4. Wait for Pages deployment to finish.
Website: https://nationvk.github.io/Love-Animation/
## 🛠 Run locally
Serve the folder over localhost (ES modules and service workers require localhost or HTTPS):
```bash
python -m http.server 8000
```
Then open http://localhost:8000.
