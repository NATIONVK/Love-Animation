## ✨ The experience
- Cinematic opening with animated typography.
- Glowing 3D-style heart, heartbeat pulse and orbiting rings.
- Twinkling starfield, floating hearts and ambient particles.
- A timed sequence of romantic messages.
- Interactive love letter overlay.
- Optional synthesized sound effects using the Web Audio API.
- Replay control, responsive layout and reduced-motion accessibility support.
- No framework, build step, API key or backend required.

## 🚀 Run it
Open `index.html` in any modern browser, or publish this repository using GitHub Pages.

### Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then press **Save**.
4. Wait for deployment. GitHub will show the live website URL in the Pages section.

## 🎨 Customize
Edit the `lines` array inside the script in `index.html` to change the animated messages. Edit the love letter text in the `letterPanel` section. Adjust the colors in the CSS `:root` variables. Everything is contained in one file, so it is easy to personalize.

## 📱 Designed for
Phones first, with a responsive layout for tablets and desktop screens.
